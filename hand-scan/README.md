# 🖐️ AI Hand Scanner

Deteksi tangan real-time menggunakan webcam. Buka 5 jari di dalam kotak selama 3 detik → video otomatis diputar.

## Install

```bash
pip install opencv-python mediapipe numpy
```

## Jalankan

```bash
python main.py
```

## Cara Pakai

1. Arahkan tangan ke **kotak** di layar
2. Buka **5 jari** penuh
3. Tahan **3 detik** sampai bar penuh
4. 🎬 Video diputar otomatis!

> Tekan `ESC` untuk keluar.

## Struktur Folder

```
hand-scan/
├── main.py
└── source/
    └── vidio.mp4   ← taruh video kamu di sini
```
